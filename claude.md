A completely custom booking system will be built for the new website, delivered as a WordPress plugin. It
is designed from the ground up around the needs of a short-stay apartment rental and handles the whole
process end to end: checking availability, taking the booking and payment, creating the invoice
automatically, sending confirmations, and later adjusting existing bookings if needed.
The goal is a plugin that manages complete online bookings for several apartments, can be operated
entirely by the owner, and needs as little upkeep as possible. The guest-facing view is clean, fast and
easy to follow — much like booking a hotel online. Administration is comfortable and mobile-friendly, and
happens directly inside the WordPress admin area.


Pricing engine Weekday rates (Sun–Thu / Fri–Sun), Hesse public-holiday logic per room, timebased rates, surcharges for extra guests & extra hours
Rate visibility All rates are publicly bookable by default; "admin only" is available for internal
special rates
Payment Prepayment / bank transfer as the fully automatic standard — no gateway fees
Short links One internal link + one booking link per room, ready to use anywhere
Calendars Availability calendar per apartment & per extra, a central blocking calendar, and a
colour calendar in the admin area
Public holidays Hesse public holidays calculated automatically, switched on per room with a
single checkbox
Flexibility The admin area can set 1-hour bookings and any special times freely
Design A fully redesigned, high-quality interface for both guests and administration

The whole system gets a fresh, high-quality design — both the front end (what guests see) and the back
end (administration). The style is distinctive and matches the new website, clearly setting it apart from offthe-shelf booking plugins.

Front End (Guest View)
The guest interface works like a modern hotel booking: clear, minimal and fast. It uses an elegant colour
scheme that matches the site, large apartment photos, calm typography, and a guided step-by-step
booking flow with no distractions.
A custom-designed booking form — nothing that looks like a standard plugin.
Large, attractive apartment presentation with a photo gallery, feature highlights and price.
A clear search bar (date · duration · guests) in the style of a hotel portal.
Fully responsive: the same high-quality experience on desktop, tablet and phone.
Adaptable to the colours and fonts of the new website (brand-ready).
Back End (Administration)
The admin area is also redesigned from scratch — tidy, modern, and deliberately not looking like the
default WordPress screens. The focus is fast, intuitive use, including from a phone.
A calm, custom layout with a clear structure and prominent action buttons.
The colour calendar as the visual centrepiece — each apartment has its own colour.
Lists shown as clear cards instead of cut-off tables (mobile-friendly).
App-like feel: can be added to the home screen and opened full-screen with its own icon.
Consistent 24-hour time format and consistent controls throughout.
Design principle
The finished product should feel like purpose-built, high-quality software. Neither the front end nor
the admin area should look like a generic booking plugin. The design and controls will be reviewed
and finalised together before handover.
